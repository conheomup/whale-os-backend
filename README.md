# Whale OS - Backend

The core API and data management system for the Whale OS personal portfolio tracking application.

This backend was built with the assistance of Large Language Models (LLMs) to streamline logic implementation and data handling, showcasing the integration of AI tools in modern development workflows.

## Tech Stack
* Python

## Features
* Handles logic for portfolio tracking and Yield-on-Cost calculations.
* Provides API endpoints for the React frontend.
* Secure and efficient data management.

## Getting Started
To run this project locally:

1. Clone the repository.
2. Install the required Python dependencies.
3. Start the local server.
